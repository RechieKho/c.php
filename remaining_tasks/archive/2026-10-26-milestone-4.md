# Milestone 4 (archived)

Scope chosen by the user: close open verify items + editor polish. Done:

- Golden corpus `tests/golden/*.{c,h}.php` + `tests/run-golden.php` (expansion, C shadow, PHP shadow; `--update` to regenerate; paths normalised to `@DIR@`). ctest `cphp_golden`.
- Proxy tests in ctest: `cphp_proxy` (real clangd, skips itself without it) and `cphp_proxy_stub` (stub servers, no clangd needed).
- **DEPFILE verified** on macOS, CMake 4.4.2: Ninja and Unix Makefiles both re-expand when a `require`d PHP file changes. Xcode is not installed here; Visual Studio is known not to support DEPFILE (warning already emitted).
- `cphpVersion` check: extension passes `--cphp-version` (its package.json version); the proxy warns once per libs.json via `window/showMessage` on `initialized`.
- `textDocument/documentSymbol` merged from clangd and the PHP server (5 s timeout falls back to clangd's list). Tested with stub servers only.
- Multi-root workspaces: one LanguageClient per workspace folder (document selector scoped with a RelativePattern); removed folders stop their client; `cphp.restart` restarts every folder with an open template.
- Extension bundled with esbuild (`npm run build` -> `out/extension.js`, `main` points there); `.vsix` went from ~600 KB to ~113 KB.
- Auto-discovery (`cmake.buildDirectory`, common build dirs, ancestors of the document) was already implemented in `discovery.js` and unit-tested in Milestone 2c; ticked off.
